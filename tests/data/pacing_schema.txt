# Pacing capture schema: the contract between the add-on's CSV writer and the capture analyzer.
#
# One checked-in fixture, read by two tests:
#   tests/test_pacing_schema.cpp  compares it with what the production code writes and names (the real CSV
#                                 writer's headers and event_type text, the *_Text functions, the enumerators).
#   tests/test_analyze_pacing.py  compares it with the analyzer's headers and value -> name tables.
#   tests/test_config_async.cpp   (config_key) compares it with the keys a first launch writes to relimiter.ini.
#   tests/test_pacing_schedule.py (config_key) compares it with the keys compare_pacing.py may write into settings.
# A change to the schema (a column, an enumerator, a name) must change this file; both tests fail until it does.
#
# Lines (blank lines and lines starting with '#' are ignored; fields are separated by spaces):
#   row_column <name>                   next column of the pacing rows header, in order
#   event_column <name>                 next column of the pacing events header, in order
#   <table> <value> <name> [retired]    value -> name of one enumeration (source_flag: the bit value)
#   config_key <name>                   one key of the [FrameLimiter] section of relimiter.ini that this build reads and writes
# retired: the build produces no such value any more; older captures carry it and the analyzer keeps its name.
#   The C++ test accepts a retired value only if the build names it exactly like this file or names it not at all.
#   A value the build names that this file lacks, and a non-retired entry the build names differently, fail.
#
# Tables bound to a *_Text function: rung, placement, fallback_reason, timing_mode, governor_cause,
# feasibility_cause, event_type (checked through the writer's event_type cell). Tables the build has no text for
# (epoch_reason, plan_status, display_source, output_kind, join_rule, identity_domain, break_reason,
# clock_map_status, pcl_status, source_flag) are bound to the enumerators: the C++ test lists every enumerator of
# the enum and fails to compile when one is added. gpu_wait_cap_cause has no enumeration in the build at all:
# all of it is retired.
